# Pocket Pause

A simple, ad-free mobile game collection with **Words, Sudoku, Snake and Tetris**.

**Production:** https://pocket-pause-ebon.vercel.app/

## Development

`main` is the source of truth for the production app. The app is intentionally lightweight and currently lives in `index.html` with no build framework required.

Future Pocket Pause changes should be committed here first and deployed from Git.
